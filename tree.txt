📊 PROJECT OVERVIEW
- **Type**: Professional RISC-V CPU Design
- **Architecture**: 32-bit RISC-V RV32I Pipeline
- **Features**: Cache-enabled memory controller, comprehensive verification

🏗️ TECHNICAL ARCHITECTURE
-------------------------
### CPU Core (cpu_core.sv)
- 5-stage pipeline (IF, ID, EX, MEM, WB)
- 32 general-purpose registers
- Configurable data/address width (8-32 bits)
- Hardware performance counters
- Debug interface support
- Branch prediction capability

### Memory Controller (memory_controller.sv)  
- 4-way set associative cache
- Write-back policy with performance optimization
- Configurable cache size (4KB-64KB)
- ECC support and cache coherency
- Performance monitoring counters
